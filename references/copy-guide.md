# Copy guide

## Hook patterns (pick the one that fits the skill best)
- **Pain call-out**: "Still writing release notes by hand?"
- **Before → after**: "30 minutes of X → one command."
- **Show, don't tell**: "I typed `/name`. Here's what came back."
- **Contrarian**: "Stop prompting Claude from scratch every time."
- **List promise**: "5 things this skill does so you don't have to."
- **Specific outcome**: "Turn any PDF into a slide deck in one step."

Concrete beats clever. Name the task, the tool (Claude Code), and the result.

## Frameworks
- **PAS** (Problem, Agitate, Solution) for pain-led variants.
- **BAB** (Before, After, Bridge) for outcome-led variants.
- Carousel arc: Hook → Problem → Insight/steps (one idea per slide) → Proof/demo → CTA ("Save this", "Follow for more", "Link in bio").
