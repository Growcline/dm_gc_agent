# growcline_dm_agent

This project makes **Growcline** marketing creatives only: static posts, carousels and reels.
For any creative request, follow `.claude/agents/growcline_dm_agent.md` exactly: the brand kit is `brand/`, scripts are in `scripts/`, output goes to `output/<topic>/<date>/`, and every image carries the red Growcline footer bar.
No publishing, no other brands, no edits to `brand/brand.json`, the logo or the footer bar.
